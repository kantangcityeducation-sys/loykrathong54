# loykrathong54

ชุดเริ่มต้นสำหรับ Google Apps Script และหน้าประชาชนแบบดูอย่างเดียวของระบบฟุตบอลลอยกระทงคัพ ครั้งที่ 54 ประจำปี 2569

## ไฟล์
- `server/google-apps-script/Code.gs` API ที่รองรับ `?a=load`, `?a=img`, `?a=ping` และ POST `{state, rows}` / `{img:{key:value}}`
- `server/google-apps-script/Public.html` หน้าประชาชนสำหรับค้นหาโปรแกรม ผลการแข่งขัน และรายชื่อทีม

## ติดตั้ง
1. เข้า https://script.google.com/ แล้วสร้างโปรเจกต์ชื่อ `loykrathong54`
2. วาง `Code.gs` ในไฟล์สคริปต์
3. เพิ่ม HTML file ชื่อ `Public` แล้ววางเนื้อหาจาก `Public.html`
4. บันทึก และอนุญาตสิทธิ์ Google Drive เมื่อ Apps Script ขอ
5. Deploy → New deployment → Web app แล้วเลือก Execute as: Me
6. ตั้งค่าการเข้าถึงตามนโยบายของหน่วยงาน หากต้องการให้ประชาชนเปิดหน้าดูได้ ต้องเปิดการเข้าถึงสาธารณะตามที่องค์กรอนุญาต
7. นำ URL `/exec` ไปใส่ในหน้าตั้งค่าของแอปเดิม
8. หน้าประชาชนใช้ URL `/exec?view=public`

## การซิงก์และข้อควรระวัง
- `LockService.getScriptLock()` ทำให้คำขอเขียนที่ผ่านสคริปต์เดียวกันทำงานทีละรายการ
- ปฏิเสธ snapshot ที่ `ts` น้อยกว่าหรือเท่ากับข้อมูลปัจจุบัน และส่ง state ฝั่งเซิร์ฟเวอร์กลับเมื่อชนกัน
- ข้อมูล state และภาพถูกเก็บเป็น JSON files ในโฟลเดอร์ Google Drive ส่วนตัวที่สคริปต์สร้างให้
- หน้า Public ไม่มี controls สำหรับแก้ไขหรือลบ และเรียกเฉพาะฟังก์ชันอ่านข้อมูล `getPublicData()`
- **ข้อจำกัดสำคัญ:** แอปเดิมส่ง state ทั้งชุด ไม่ใช่การแก้ไขรายช่อง ดังนั้น timestamp/lock ป้องกันการเขียนทับแบบชนกันได้ระดับหนึ่ง แต่ไม่สามารถผสานการแก้คนละช่องของสองเครื่องอัตโนมัติได้ ต้องทดสอบ 5 เครื่องจริงก่อนใช้งานจริง และให้ผู้ใช้กด SAVE/ซิงก์หลังโหลดข้อมูลล่าสุด
- โค้ดนี้ยังไม่ได้ถูก Deploy ไปยังบัญชี Google Apps Script และยังไม่ใช่ระบบที่ผ่านการทดสอบภาคสนาม
